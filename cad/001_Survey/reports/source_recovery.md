# Source preservation and prior-session recovery

The user authorized recovering needed transcription material from earlier PDF-creation sessions when it was absent from the repository, and including it in this effort's ZIP.

## Result

The current repository at `a938a6e475da3263ede6a68b956da6d613964c26` contains structured SNL tables and notes, handbook table and reconstruction data, the Liberty master transcription, gun line data, and Jordan/patent reviewed transcriptions. Those were used directly. The package freezes the inputs consumed by the survey and additionally preserves 597 tracked project text/data/script files in `source_transcription_snapshot/`, with their original relative paths and SHA-256 hashes. Source PDF text/page maps provide searchable prose in addition to the native transcription data.

A targeted prior-session context search named the SNL G-13, Preliminary Handbook, Liberty engine, Hotchkiss, Jordan and Alden PDF efforts and asked specifically for missing full transcripts, ZIPs and uncommitted source paths. It returned evidence for:

- `Handbook_Feasibility_Study.pdf`, from an earlier, explicitly incomplete reconstruction stage. That stage recorded 251 numbered pages, 126 unique JPEGs, and an advertised set of 143 plates plus one insert; the insert had not been separately identified.
- `Handbook_Master_001-251_v13.pdf`, with native engine prose/specifications and aircraft-data caveats.
- `Liberty_Master_scans0001-0162_v09_20260913T182703Z.pdf`, containing prose and figure text.
- The companion handbook errata and the earlier observation that the SNL p. 277 foldout is a useful longitudinal-section source while the handbook insert was missing.

The returned result did not identify a recoverable additional complete transcript ZIP, missing text segment, or local artifact path absent from the current repository. No newly recovered full session transcript is therefore claimed or fabricated. The earlier feasibility-stage incompleteness is not automatically applied to the later master: this survey states its own current coverage from the actual repository inputs.

The preservation action is concrete: all available current text sources are frozen in this ZIP, including substantially more project source data than the database directly consumes. The snapshot is not a copy of the full conversation histories and does not duplicate the repository's original images/PDFs. If a later recovery yields another transcript or the missing handbook insert, it should be added as a new source revision and reconciled with the frozen records.
