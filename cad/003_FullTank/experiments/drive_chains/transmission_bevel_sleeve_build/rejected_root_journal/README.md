# Rejected root-diameter journal trial

These archived generator/controls files produced the local static checks in
`local_report.json`. `local_passage_report.json` adds two actual M261 bush
translations against the same reconstructed shaft. Although the assembled
parts did not overlap, translating the bush by −60 or +60 mm produced
39,566.872 or 20,404.538 mm³ of spline interference. This is a rejected
assembly interpretation, not a qualified candidate.

The input native document is the retained
`../../transmission_sun_retention_build/TransmissionSunRetentionCandidate.FCStd`,
SHA-256 `1982f905cced225f7ffe908ad2913996c627278ea993916f7b7e27cf69bfb4e6`.
The earlier six-argument `sleeve_parts` entry point here is deliberately
preserved; the current builder has subsequently added the M268/M267 correction
and central clutch spline and uses a different signature.

This directory contains no promoted native model. The current candidate uses
larger smooth journals and bores, with independently checked outboard passage.
