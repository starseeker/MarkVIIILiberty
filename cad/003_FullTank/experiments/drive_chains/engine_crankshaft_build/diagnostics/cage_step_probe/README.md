# Spherical cage pocket exchange probe

Default Z parametrization passes native validity but fails STEP transfer. An X
axis normal to the trimming planes passes both tested sizes and both definition
and installed frames. The native X/Z material-equivalence probe also passes.

The initial centroid/volume matching misidentified some negative-volume invalid
STEP solids. Bounds and isolated exports identify the cages. Retained scripts,
STEP files and reports distinguish that diagnostic mistake from the geometry
failure and its verified repair.
