The default single-object STEP export removed the installed translation. The definition passed unchanged strict material, mass and tolerance checks, while the installed export had identical bytes to the definition export and a2458.48mm centroid error. The13 native/interface/context checks passed. Retain this failure; fix the explicit export placement setting without changing geometry or tolerances.

A three-case box probe retained under setting_probe compares default settings, Mod/Import/ExportKeepPlacement=True and the same key in Mod/Part/STEP. Only the Mod/Import setting preserves the100,200,300mm translation. The final stock checks use that explicit setting and write.surfacecurve.mode=1; native material and all acceptance tolerances remain unchanged. Both definition and installed exports then pass.
