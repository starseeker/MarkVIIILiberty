# Reviewed M4130 mounting prototype

Thirty physical occurrences include the channel, four cleats with floor bolt sets,
twelve rivets and the drilled floor receiver. This isolated model supplies the
[integrated checkpoint](../channel_integrated01/README.md).

Nominal and [thicker-cleat](../channel_mount_variation02/report.json) trials each
pass 75 native/interface checks, 57 local material pairs, surrounding-material
checks and 37 strict STEP comparisons. The actual saved native, source review,
fixed-registration overlay and fresh reproduction were reviewed before integration.

`input_channel_mount_controls02.json` and `report.json` are the authoritative
controls for this revision. The prototype's generic `ParameterUpdate` metadata
still names controls01; the integrated definitions carry the corrected instruction.
Earlier interfering layouts remain in `channel_mount01` and
`channel_mount_variation01`. Historical profile, handedness, rivet stock datum
and source count differences remain documented approximations.
